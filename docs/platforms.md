# Platforms

For each chat platform the archive reads, each connector that reads it: how its messages arrive, how its calls arrive and whether they say how long they were, how it treats end-to-end-encrypted chats, and how it keeps up. Each platform's status and when it last synced are in the viewer's Events > Sources.

Written from the connectors' manifests (`server/connectors/*/manifest.ts`) by `npm run docs`; change a manifest, never this file.

| Platform | Connector | Way in | Messages | Calls | Encrypted chats | Keeps up |
| --- | --- | --- | --- | --- | --- | --- |
| Messenger | `facebook-dyi` | Requested export | Yes | With their lengths: call records in their chats, each with how long it was connected (0 when not answered) | leaves out the end-to-end-encrypted chats, all but their history from before they moved: messenger-export brings them | Import again, from where the last import reached |
| Messenger | `messenger-export` | Requested export | Yes | No lengths: Add length: a call is an empty link, with no length or answer, so each is a call of no known length | the end-to-end-encrypted chats, from the phone app's download of its message storage | Import again, whole each time; what the archive has is skipped |
| Instagram | `instagram-dyi` | Requested export | Yes | With their lengths: call records in their chats, each with how long it was connected (0 when not answered) | reads what Instagram's download holds; whether it leaves out end-to-end-encrypted chats, as Facebook's does, is not known yet | Import again, from where the last import reached |
| WhatsApp | `matrix-whatsapp` | Live | Yes | No call records: the bridge passes on no call's length or outcome, only a notice when a call rings on it, kept as a system message; WhatsApp's calls come from whatsapp-db | all of WhatsApp is end-to-end encrypted; the bridge is one of the captain's own linked devices, so it reads every chat | Follows along by itself |
| WhatsApp | `whatsapp-db` | iPhone backup | Yes | Some with their lengths; Add length for the rest: WhatsApp's call history and the call records in its chats: which way, voice or video, answered or not, and how long, all but one answered on another device; a three-way call outside a group is a call with each person the copy knows, the rest counted unnamed | all of WhatsApp is end-to-end encrypted; the app's own databases hold every chat readable | Import again, whole each time; what the archive has is skipped |
| iMessage | `imessage-db` | This Mac | Yes | No call records: FaceTime calls come from the phone's call history (call-history) | iMessage is end-to-end encrypted on the way; the Messages app's own database holds it readable | Import again, from where the last import reached |
| Telegram | `matrix-bridge` | Live | Yes | Some with their lengths; Add length for the rest: the bridge's notice for each call made or ended while it runs ("Call ended (12 minutes)"; it never backfills them), read as a call record: a one-to-one call with how long it was connected (0 when missed or rejected); a group's video chat with no length unless first seen ended | secret chats, Telegram's only end-to-end-encrypted ones, stay on the device that started them, so the bridge never sees them | Follows along by itself |
| X | `x-archive` | Requested export | Yes | No call records: none: the archive holds no calls (its direct messages are messages, joins and leaves; XChat's, messages, read marks and key changes) | XChat, X's newer end-to-end-encrypted chats, cannot be read from the archive: they are only counted | Import again, whole each time; what the archive has is skipped |
| Signal | `signal-export` | Requested export | Yes | No lengths: Add length: one-to-one call records say whether a call was answered, never how long; group calls are only counted | all of Signal is end-to-end encrypted; Signal Desktop's own export holds every chat readable, all but disappearing messages | Import again, whole each time; what the archive has is skipped |
| Discord | `discord-package` | Requested export | Yes | No call records: none: the package gives each message only its id, time, text and attachments, so a call is an empty message it does not tell from a sticker or an embed (kept, without text, and counted) | Discord's messages are not end-to-end encrypted; the package holds the captain's own as Discord keeps them | Import again, whole each time; what the archive has is skipped |
| WeChat | `wechat-ios` | iPhone backup | Yes | Some with their lengths; Add length for the rest: call records with how long each was connected, all but those WeChat compressed, which only its dictionary reads | WeChat is not end-to-end encrypted; the Mac app encrypts its databases on disk, so the iPhone backup's are read | Import again, whole each time; what the archive has is skipped |
| Phone | `call-history` | This Mac | No, calls only | With their lengths: every phone and FaceTime call the call history keeps (about a year back): when, how long, which way, answered or not | None | Import again, whole each time; what the archive has is skipped |
